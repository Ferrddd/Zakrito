# Запуск
## Установка
`make install` -- создает виртуальное окружение и поттягивает все необходимые зависимости

`make copy-env` -- перезаписывает данные из .env.example в .env файл. Необходимо запустить, если .tnv нету, или он некорректен

## Другие запуски
`make update-venv` -- проверят установленны ли все необходлимые пакеты из `requirements.txt` и недостающие пакет устанавливает в вируальное окружение

`make lint` -- запускает проверку кодстайла
